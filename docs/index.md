# PARADIGMSOL3S Monorepo Documentation Index

## Overview

This monorepo contains the complete CI/CD pipeline infrastructure for PARADIGMSOL3S, a pioneering decentralized footwear innovation project on blockchain.

## Repository Structure

- **[.github/workflows/](https://github.com/PARADIGMSOL3S/paradigmsol3s-monorepo/tree/main/.github/workflows)** - GitHub Actions CI/CD workflows
  - [ai-validation.yml](https://github.com/PARADIGMSOL3S/paradigmsol3s-monorepo/blob/main/.github/workflows/ai-validation.yml) - AI-powered code review & validation
  - [golden-deployment.yml](https://github.com/PARADIGMSOL3S/paradigmsol3s-monorepo/blob/main/.github/workflows/golden-deployment.yml) - Production deployment pipeline
  - [security-scan.yml](https://github.com/PARADIGMSOL3S/paradigmsol3s-monorepo/blob/main/.github/workflows/security-scan.yml) - Comprehensive security scanning

- **[scripts/](https://github.com/PARADIGMSOL3S/paradigmsol3s-monorepo/tree/main/scripts)** - Automation and setup scripts
  - [gemini-cli-setup.sh](https://github.com/PARADIGMSOL3S/paradigmsol3s-monorepo/blob/main/scripts/gemini-cli-setup.sh) - Gemini AI CLI installation script

- **[docs/](https://github.com/PARADIGMSOL3S/paradigmsol3s-monorepo/tree/main/docs)** - Documentation hub (this folder)
  - metrics/ - Performance and analytics docs
  - security/ - Security guidelines and reports
  - architecture/ - System architecture documentation
  - runbooks/ - Operational runbooks

- **[sandbox/](https://github.com/PARADIGMSOL3S/paradigmsol3s-monorepo/tree/main/sandbox)** - Experimentation space
